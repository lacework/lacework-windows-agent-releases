# Lacework Windows Agent Releases

This Lacework agent GitHub site provides the officially supported Lacework Windows agent releases. From this site, you can download and install the Lacework Windows agent.

# Lacework Windows Agent Documentation

For information about supported Windows operating systems, how to configure the agent, agent features, workload dossiers, and more, see [Lacework Windows Agent Documentation](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/876164/windows-agent-based-workload-security).

# Releases

In the right frame, click **Releases** to view the available agent releases.
The section for each release lists the files you can download to install the agent. Each release also contains a link to the specific agent release notes.
To view the release notes for all agent releases, see [FortiCNAPP Release Notes](https://docs.fortinet.com/document/forticnapp/latest/release-notes).

# Install Agents

This README.md file provides instructions for installing the agent from this GitHub repository. You can also install the agent from the FortiCNAPP Console. For information about the different methods for installing the agent, see [Windows Agent Installation Options](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/566236/windows-agent-install-options).

## Installation Prerequisites

Complete the following steps before you install the agent:

1. Ensure that the Lacework Windows agent supports the installed OS. See [Windows Agent Installation Prerequisites](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/902600/windows-agent-installation-prerequisites).
2. Ensure that your machine meets the minimum CPU and memory requirements for the Lacework Windows agent. See [Windows Agent Installation Prerequisites](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/902600/windows-agent-installation-prerequisites).
3. Obtain an access token for the Windows agent using the FortiCNAPP Console. See [Managing Agent Access Tokens](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/698365/managing-agent-access-tokens).
4. Download the Windows agent MSI package from this GitHub site or the FortiCNAPP Console. You can also download Windows agent installer scripts using the FortiCNAPP Console. See [Download the Windows Agent Installer](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/1455/downloading-the-windows-agent-installer).

## Install Lacework Windows Agent
You can use one of the following methods to install the agent:
* Install Windows agent using the MSI installer from the command line, with or without config.json, interactively or silently. See [Installing the Windows Agent from the Command Line](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/310677/installing-the-windows-agent-from-the-command-line).
* Install Windows agent with Powershell script. See [Use a PowerShell Script to Install Windows Agent](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/169764/installing-the-windows-agent-using-a-powershell-script).
* Install Windows agent with Azure Resource Manager(ARM). See [Install Windows Agent with Azure Resource Manager](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/540656/installing-windows-agent-with-azure-resource-manager).
* Install Windows agent on Azure VMs using Terraform. See [Install Windows Agent on Azure VMs using Terraform](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/768934/installing-windows-agent-on-azure-vms-using-terraform).
* Install Windows agent with Packer. See [Install Windows Agent with Packer](https://docs.fortinet.com/document/forticnapp/latest/administration-guide/769849/install-windows-agent-on-aws-with-packer).
